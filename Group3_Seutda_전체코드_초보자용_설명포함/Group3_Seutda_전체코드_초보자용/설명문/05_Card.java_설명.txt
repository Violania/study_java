[Card.java 설명]

1. 이 파일의 역할
- 화투 카드 한 장의 정보를 만들고, 카드 두 장을 비교해서 섯다 족보를 계산합니다.

2. 카드 번호를 1~20으로 만든 이유
- 섯다에 사용하는 10개월 카드가 각 2장씩 있으므로 총 20장을 번호로 관리하기 쉽도록 만들었습니다.
- month = ((number - 1) / 2) + 1 계산으로 번호를 월로 바꿉니다.

3. 주요 메서드
- createDeck(): 1번부터 20번까지 Card 객체를 만들어 한 벌의 덱을 만듭니다.
- evaluate(a, b): 카드 두 장을 받아 38광땡, 땡, 알리, 독사, 끗 등 족보를 순서대로 검사합니다.
- getDdangRank(): 같은 월 두 장일 때 어떤 땡인지 switch문으로 반환합니다.
- getKkutRank(): 카드 월의 합으로 몇 끗인지 switch문으로 반환합니다.
- matches(): 카드 순서와 상관없이 특정 두 월 조합인지 검사합니다.

4. Rank enum을 사용한 이유
- 족보마다 이름과 비교 점수가 필요합니다.
- 예를 들어 장땡은 이름 "장땡"과 점수 200을 한 세트로 묶어두면 승패 비교가 쉬워집니다.
- enum 자체는 Java의 기본적인 상수 묶음 기능이며, 복잡한 ordinal 계산은 사용하지 않았습니다.

5. 발표할 때 한 문장
"Card.java는 카드 정보를 만드는 부분과 두 장의 카드를 섯다 족보로 바꾸는 규칙을 담당합니다."

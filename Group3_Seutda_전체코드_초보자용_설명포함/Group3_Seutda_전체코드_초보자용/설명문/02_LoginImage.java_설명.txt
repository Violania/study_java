[LoginImage.java 설명]

1. 이 파일의 역할
- 로그인 화면 뒤에 보이는 배경 이미지를 불러오고 화면에 그립니다.

2. 왜 별도 파일로 만들었는가
- Main.java에 이미지 출력 코드까지 넣으면 로그인 처리와 그림 출력 코드가 섞여 복잡해집니다.
- 그래서 이미지 그리기만 담당하는 Panel 클래스로 따로 분리했습니다.

3. 주요 코드
- LoginImage(int width, int height): 패널 크기를 정하고 배경 이미지를 읽습니다.
- paint(Graphics g): 현재 창 크기에 맞춰 배경 이미지를 그립니다.
- update(Graphics g): 화면이 다시 그려질 때 paint()를 사용하도록 합니다.

4. 이미지 파일을 두 방식으로 찾는 이유
- 실행 폴더의 resources/images 폴더에 이미지가 있을 수도 있고,
- Java 리소스로 포함되어 있을 수도 있기 때문에 두 위치를 차례대로 확인합니다.

5. 발표할 때 한 문장
"LoginImage.java는 로그인 기능과 배경 이미지 출력 기능을 분리하기 위해 만든 전용 이미지 패널입니다."

[프로젝트의 Java 외 파일 설명]

1. resources/images/
- 카드 앞면, 카드 뒷면, 로그인 배경 이미지가 들어 있습니다.
- Java 코드에서 loadImage()로 읽어 화면에 표시합니다.

2. data/accounts.txt
- 로그인 아이디와 해시된 비밀번호 값을 저장합니다.
- 비밀번호 원문을 그대로 저장하지 않습니다.

3. data/game_records.txt
- 게임 시간, 아이디, 승패, 보유금, 결과 정보를 저장합니다.

4. data/README.txt
- data 폴더가 어떤 용도로 사용되는지 안내합니다.

5. 실행하기.bat
- Windows에서 프로젝트를 쉽게 컴파일하고 실행하기 위한 배치 파일입니다.

6. 서버만실행.bat
- 멀티플레이 서버만 따로 실행할 때 사용하는 배치 파일입니다.

7. MULTIPLAYER_README.txt
- 멀티플레이 실행 방법과 접속 방법을 설명합니다.

8. 발표용_코드_안내.txt
- 발표할 때 어떤 파일부터 보면 좋은지 간단히 정리한 안내 파일입니다.

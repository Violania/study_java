[Main.java 설명]

1. 이 파일의 역할
- 프로그램을 처음 실행했을 때 가장 먼저 실행되는 파일입니다.
- 로그인 화면을 만들고 아이디/비밀번호를 입력받습니다.
- 로그인에 성공하면 GameModeFrame으로 이동합니다.

2. 왜 이런 코드를 썼는가
- Java 프로그램은 main() 메서드에서 시작하기 때문에 실행 시작점을 Main.java에 모았습니다.
- 로그인 화면과 실제 게임 화면을 분리하면 한 파일이 너무 복잡해지지 않습니다.
- 아이디와 비밀번호가 비어 있을 때는 다음 화면으로 넘어가지 않도록 먼저 검사합니다.
- 로그인 판정 자체는 SaveData.login()에 맡겼습니다. Main.java가 파일 저장 기능까지 직접 처리하면 역할이 너무 많아지기 때문입니다.

3. 주요 코드
- main(): 로그인 창을 만들고 프로그램을 시작합니다.
- ActionListener: Login 버튼이나 비밀번호 입력창에서 Enter를 눌렀을 때 로그인을 시도합니다.
- WindowAdapter: 창의 X 버튼을 눌렀을 때 프로그램을 정상 종료합니다.

4. 발표할 때 한 문장
"Main.java는 프로그램의 시작점이며 로그인 화면을 만들고, 로그인 성공 후 게임 모드 선택 화면으로 넘기는 역할을 합니다."

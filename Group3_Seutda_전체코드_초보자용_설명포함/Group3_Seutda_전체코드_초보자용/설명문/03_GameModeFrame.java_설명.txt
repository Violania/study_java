[GameModeFrame.java 설명]

1. 이 파일의 역할
- 로그인 후 혼자 하기, 방 만들기, 방 참가 중 하나를 고르는 화면입니다.

2. 왜 이런 구조를 썼는가
- 혼자 하기와 멀티플레이는 실행 방식이 다르기 때문에 게임 시작 전에 모드를 선택하도록 만들었습니다.
- ActionListener를 클래스에 implements해서 여러 버튼의 동작을 actionPerformed() 한 곳에서 확인할 수 있게 했습니다.

3. 주요 코드
- 생성자: 버튼, IP 입력창, 안내 문구를 배치합니다.
- actionPerformed():
  · 혼자 하기 -> GameFrame 실행
  · 방 만들기 -> SeutdaServer 실행 후 MultiplayerFrame 실행
  · 방 참가 -> 입력한 IP로 MultiplayerFrame 실행

4. 왜 방 만들기에서 서버를 먼저 실행하는가
- 방을 만든 컴퓨터가 호스트 역할을 하므로 그 컴퓨터에서 서버가 먼저 열려야 다른 사람이 접속할 수 있습니다.

5. 발표할 때 한 문장
"GameModeFrame은 로그인 다음 단계에서 싱글플레이와 멀티플레이의 실행 경로를 나누는 메뉴 화면입니다."
